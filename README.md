# Jake — Missão Puberdade

PWA educativo offline em HTML/CSS/JavaScript.

## Como publicar
1. Envie todo o conteúdo desta pasta para um repositório GitHub.
2. Ative GitHub Pages para a pasta raiz.
3. Abra o endereço do Pages no navegador.
4. Use **Instalar app** ou **Adicionar à tela inicial**.
5. Depois da primeira abertura, o jogo fica disponível offline.

## Controles
- Computador: setas ou A/D para andar; espaço, W ou seta para cima para pular.
- Celular/tablet: botões na tela.
- Resposta correta: +10 moedas.
- Erro ou colisão: perde uma vida e reinicia a fase.
- Só passa de fase depois de acertar todas as perguntas.

## Offline e som
- As imagens ficam dentro do próprio PWA.
- O service worker guarda os arquivos em cache.
- Os efeitos sonoros e a música são sintetizados pelo navegador, sem depender de arquivos externos ou internet.
